# gjallar-docs

Documentation for [Gjallar](https://github.com/heimdallr-dev/gjallar), published with MkDocs to GitHub Pages.

```bash
pip install -r requirements.txt
mkdocs serve        # http://127.0.0.1:8000
```

Content is in `docs/`; edits that change behaviour descriptions should land together with the code change in the core repo.
